# Patches

Store downstream source patches here, grouped by their KDE upstream repository.

Expected layout:

```text
patches/
  systemsettings/
  plasma-desktop/
  plasma-nm/
  powerdevil/
  kscreen/
```

Patch filenames should be ordered and descriptive, for example:

```text
0001-systemsettings-adjust-ro-asd-category-labels.patch
```

Each patch must have matching provenance notes in the same directory or in `docs/`.
